# teacherc-

## C++ Учебник для школьников

Интерактивный курс по C++ с 18 темами, тестами и AI-помощником.

---

## Версии

### Консольная версия (`OBYCHENIE/OBYCHENIE.vcxproj`)
Оригинальная текстовая программа с интерфейсом в командной строке.

**Сборка:**
1. Открыть `OBYCHENIE/OBYCHENIE.slnx` в Visual Studio 2022
2. Выбрать проект **OBYCHENIE** → Configuration: `Release`, Platform: `x64`
3. Build → Build Solution

### GUI версия на ImGui (`OBYCHENIE_GUI.vcxproj`) ✨ НОВАЯ

Красивый оконный интерфейс на [Dear ImGui](https://github.com/ocornut/imgui) + DirectX 11.

**Особенности GUI:**
- 🌙 Тёмная тема "One Dark" — не режет глаза при долгом чтении
- 🎨 Подсветка синтаксиса C++ кода (ключевые слова, строки, комментарии, цифры, директивы)
- 📚 Левая боковая панель со списком всех 18 тем и индикатором прогресса
- 📖 Вкладки урока: Теория | Код | Тест | AI-вопрос
- ✅ Интерактивный тест с визуальной обратной связью (зелёный/красный)
- 🤖 Встроенный AI-помощник (OpenRouter API, работает в фоне)
- 📊 Экран статистики с таблицей прогресса по темам
- 🔥 Счётчик серии дней занятий

**Сборка GUI:**
1. Открыть `OBYCHENIE/OBYCHENIE.slnx` в Visual Studio 2022
2. Выбрать проект **OBYCHENIE_GUI** → Configuration: `Release`, Platform: `x64`
3. Build → Build Solution

**Требования для GUI:**
- Windows 10/11 (x64)
- Visual Studio 2022 с компонентом "Desktop development with C++"
- DirectX 11 (входит в стандартную Windows)
- `curl.exe` в PATH (для AI-помощника) — обычно встроен в Windows 10/11

**Структура файлов GUI:**
```
OBYCHENIE/
  OBYCHENIE/
    imgui_main.cpp          ← Главный файл GUI приложения
    cpp_learning_program.cpp← Данные курса (18 тем, тесты, AI)
    imgui/                  ← Dear ImGui v1.91.8
      imgui.h / imgui.cpp   ← Ядро ImGui
      imgui_draw.cpp
      imgui_tables.cpp
      imgui_widgets.cpp
      imgui_internal.h
      backends/
        imgui_impl_win32.*  ← Win32 бэкенд
        imgui_impl_dx11.*   ← DirectX 11 бэкенд
  OBYCHENIE_GUI.vcxproj     ← Проект для GUI версии
  OBYCHENIE.slnx            ← Файл решения (оба проекта)
```
